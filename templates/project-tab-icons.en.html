Project Tab Icons customizes macOS project window tabs in IntelliJ IDEA. It’s available as a ZIP from GitHub.

01

Install the plugin.

Download the ZIP. In IDEA, open Settings → Plugins → the gear menu → Install Plugin from Disk.

02

Bring projects together.

Open projects in separate windows, then choose Window → Merge All Project Windows.

03

Find your style.

Open Settings → Appearance & Behavior → Project Tab Icons. Choose a preset, adjust the preview and apply.
