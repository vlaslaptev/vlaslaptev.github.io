Устройтесь поудобнее.

Project Tab Icons оформляет оконные вкладки проектов IntelliJ IDEA на macOS. ZIP плагина доступен на GitHub.

01

Установите плагин.

Скачайте ZIP. В IDEA откройте Settings → Plugins → меню с шестерёнкой → Install Plugin from Disk.

02

Соберите проекты вместе.

Откройте проекты в отдельных окнах и выберите Window → Merge All Project Windows.

03

Выберите свой стиль.

Откройте Settings → Appearance & Behavior → Project Tab Icons. Выберите пресет, настройте предпросмотр и примените.
